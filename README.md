# 🚀 Tank-Game (3D Physics-based Combat)

A high-speed, physics-driven 3D tank combat game built in **Unity** using the **Universal Render Pipeline (URP)**.

![Unity](https://img.shields.io/badge/Unity-2023.x%2B-blue?logo=unity) 
![License](https://img.shields.io/badge/License-MIT-green)

---

## 🎮 Game Features

- **Physics-Based Movement**: Realistic tank handling with acceleration and weight.
- **War Thunder Style Controls**: Smooth mouse-driven turret and gun rotation.
- **Combat Loop**: Interactive projectile system with enemy tanks and structural damage.
- **Dynamic Camera**: 3rd-person orbit camera for an immersive battlefield view.

## 🛠️ Technology Stack

- **Engine**: Unity 6000.0.38f1 (or compatible)
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Language**: C#
- **Key Packages**:
  - Cinemachine (Camera Management)
  - ProBuilder (Level Prototyping)

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Seungpyo1007/Tank-Game.git
   ```
2. **Open in Unity**: Launch Unity Hub and open the `Tank-Game` folder.
3. **Setup URP**: Ensure the URP Asset is assigned in `Project Settings > Graphics`.
4. **Play**: Open `Assets/Scenes/Main.unity` and hit **Play**.
