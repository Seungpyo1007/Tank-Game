## 🇰🇷 한국어

유니티(Unity) **Universal Render Pipeline (URP)**를 사용한 물리 기반 3D 탱크 시뮬레이션 게임입니다.

### 🎮 주요 특징
- **물리 기반 이동**: 탱크의 가속도와 무게를 반영한 사실적인 주행 물리.
- **워크 썬더 스타일 조작**: 마우스 이동에 반응하는 부드러운 포탑 및 포신 회전.
- **전투 시스템**: 탱크 포탄 발사 및 적 탱크와의 상호작용이 포함된 기본 전투 루프.
- **다이나믹 카메라**: Cinemachine을 이용한 3인칭 궤도 카메라 시스템.

### 🛠️ 기술 스택 및 환경
- **Engine**: Unity 6000.4.0f1
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Packages**: Cinemachine, ProBuilder

### 🚀 시작하기
1. **저장소 클론**:
   ```bash
   git clone https://github.com/Seungpyo1007/Tank-Game.git
   ```
2. **유니티에서 열기**: Unity Hub를 통해 `Tank-Game` 폴더를 엽니다.
3. **URP 설정**: `Project Settings > Graphics`에서 URP Asset이 제대로 할당되어 있는지 확인하세요.
4. **플레이**: `Assets/Scenes/Main.unity` 씬을 열고 플레이 버튼을 누릅니다.

## 🇺🇸 English

A physics-driven 3D tank combat game built with **Unity** using the **Universal Render Pipeline (URP)**.

### 🎮 Key Features
- **Physics-Based Movement**: Realistic tank handling with modeled acceleration and mass.
- **War Thunder Style Controls**: Smooth mouse-driven turret and gun barrel rotation.
- **Combat Loop**: Initial combat system featuring projectile firing and enemy tank interactions.
- **Dynamic Camera**: 3rd-person orbit camera system powered by Cinemachine.

### 🛠️ Tech Stack & Environment
- **Engine**: Unity 6000.4.0f1
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Packages**: Cinemachine, ProBuilder

### 🚀 Getting Started
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Seungpyo1007/Tank-Game.git
   ```
2. **Open in Unity**: Launch the project folder via Unity Hub.
3. **URP Setup**: Ensure the URP Asset is correctly assigned in `Project Settings > Graphics`.
4. **Play**: Open the `Assets/Scenes/Main.unity` scene and hit **Play**.
